# Changelog

All notable changes to KAYF Contribution Studio are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-05

### Added

- Native SwiftUI contribution designer for macOS 15+
- Deterministic natural and preset activity generators
- Manual painting, keyboard editing, themes, and contribution text art
- Searchable commit planning and CSV export
- Real dated Git commit generation with author and committer timestamps
- Dry-run validation, progress, pause, cancellation rollback, and history undo
- Repository identity and remote management with explicit push confirmation
- Local project, history, settings, and logs
- Unit, integration, and UI smoke tests
- Signed/notarized DMG release pipeline and GitHub Releases automation

[1.0.0]: https://github.com/vKAYFv/KAYF-Contribution-Studio/releases/tag/v1.0.0
